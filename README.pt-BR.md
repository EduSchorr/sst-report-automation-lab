# Laboratório de Automação de Laudos SST

### Python · análise de acervo · anonimização · pesquisa documental

Este repositório representa a **etapa de pesquisa e preparação de dados** que antecedeu o desenvolvimento de um fluxo estruturado para geração de laudos de SST.

## Objetivo

As ferramentas analisam um acervo local sem publicar os documentos originais. O foco é identificar padrões recorrentes de estrutura, títulos, regras, evidências e modelos que possam alimentar templates e automações futuras.

## O que o projeto demonstra

- inventário e análise de metadados do acervo;
- extração de texto de documentos;
- análise de regras, títulos e padrões;
- preparação com foco em anonimização;
- geração de amostras controladas;
- divisão e validação de conjuntos de arquivos;
- produção de documentação de contexto para o sistema;
- separação entre acervo de pesquisa e aplicação de produção.

## Relação com o Peritus SST

Este projeto representa uma camada anterior de pesquisa. O produto resultante está publicado separadamente no repositório **Peritus SST**.

## Privacidade

O acervo técnico original não está neste GitHub. Casos reais, nomes de partes, documentos privados, bancos de produção e informações profissionais foram excluídos.
